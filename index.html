Retail Analytics Copilot

Hybrid RAG + SQL AI agent

View repository
01

Problem

Business teams often need answers that live in two different places at once — unstructured knowledge like product docs and policies, and structured data like sales tables. Getting an answer usually means knowing which tool to use, then writing the search or the SQL query by hand.

02

Solution

I built an agent that reads the question, decides whether it needs retrieval, SQL, or both, and plans the steps to answer it — including repairing its own SQL when a query fails, and synthesizing a final answer with a confidence score and citations.

Data Warehouse & Analytics

SQL Server medallion data warehouse

View repository
01

Problem

Raw ERP and CRM exports arrive as inconsistent CSV files — different naming, formats, and quality — which makes them unreliable to analyze directly.

02

Solution

I designed a medallion architecture that ingests the raw files, cleans and standardizes them, and models the result into a star schema, so downstream analytics queries stay simple and fast.

Engineering highlights

  • Bronze layer for raw, unmodified ingestion
  • Silver layer for cleansing, standardization, and transformation
  • Gold layer as the analytical, query-ready layer
  • Data validation rules across the pipeline
  • Star schema with fact and dimension tables
  • Documented data catalog and consistent naming conventions
06

Results

The outcome is a documented, query-ready warehouse: a full data catalog, consistent naming conventions, and analytics-ready Gold-layer tables built on fact and dimension models — all available in the repository.

About

I'm an AI & Data Engineer based in Egypt, currently completing a dual degree between Ain Shams University and the University of East London. I build the systems businesses actually need in order to work with their data — pipelines that clean and move it, warehouses that structure it, and AI agents that can answer questions about it in plain language.

My work sits across four areas: AI and RAG systems, data engineering, SQL and data warehousing, and machine learning — using tools like Python, SQL Server, LangGraph, DSPy, and scikit-learn. I like problems that start out messy: scattered CSV exports, a knowledge base nobody has time to search, a spreadsheet that should really be a database.

If you have a data or AI problem and need someone who can scope it, build it, and explain how it works, I'd like to hear about it.
